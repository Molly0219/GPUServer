# Ateamdata

Static website for GPU server sourcing and systems integration. The primary color is **#76b900**. The catalog features Supermicro SYS-821GE-TNHR, Dell PowerEdge XE9680 and HPE Cray XD670, with NVIDIA H100 / H200 SXM configuration options.

## Publishing contract

- The ready-to-serve HTML, CSS, JavaScript and images are committed in their existing root locations. Publish through the existing repository update process.
- Keep the client's current GitHub Pages publishing branch / folder, domain settings and DNS configuration. No new GitHub Actions, account credentials, environment variables or backend are required.
- Preserve both `CNAME` and `docs/CNAME` (`ateamdata.com`). The `docs` folder is not repurposed as a new website output directory.
- Existing public routes remain: `index.html`, `product.html`, `solution.html`, `service.html`, `about.html`, `benchmarks.html`, `contact.html`, and `404.html`.
- `gpu-matrix.html` adds a static NVIDIA architecture × product-format reference. It uses the same publish location and relative asset paths.
- Pages use relative links and local assets. The custom 404 page uses a root base URL for the established custom domain.
- Account-level Pages settings and production publication cannot be verified from this checkout alone. Publishing updated files still requires the existing authorized repository update path.

## Local maintenance

No build is required to **serve or publish** the committed files. Optional authoring tools use Node.js:

```sh
npm start        # local preview at http://127.0.0.1:4173
npm run build    # regenerate root HTML after editing source templates / product data
npm run icons    # regenerate PNG / ICO fallbacks after editing the SVG tab icon
npm test         # browser checks with the existing Playwright dev dependency
```

- `site/products.mjs`: product specifications, source links, images, GPU data and contact information.
- `site/gpu-matrix.mjs`: curated GPU families, product formats, representative entries, official sources and review date.
- `scripts/render-gpu-matrix.mjs`: static matrix markup, terminology and scope notes.
- `css/gpu-matrix.css` / `js/gpu-matrix.js`: matrix layout, search, family/format filters, shareable filter URLs and CSV export.
- `scripts/build-site.mjs`: shared layout and page content. Regenerate and commit the resulting root HTML with source edits.
- `css/site.css`: responsive layout, brand colors and reduced-motion support.
- `images/ateamdata-mark.svg`: green A monogram on a dark background for browser tabs. PNG / ICO fallbacks and the Apple touch icon are generated by `scripts/build-icons.mjs`; all output icons are committed. The legacy `images/favicon.ico` address is retained, with a root `favicon.ico` fallback. Versioned icon links refresh previously cached tab artwork.
- `js/site.js`: mobile navigation, catalog filters, configuration selection and inquiry preparation.
- `scripts/check-site.mjs`: desktop/mobile page checks, static paths, navigation, filtering, email preparation, no-JavaScript fallback and deployment invariants.

Install the package-lock dependencies (`npm ci`) only for development/testing if needed. Playwright needs an installed Chromium browser (`npx playwright install chromium`) for the checks. Neither is required on GitHub Pages.

## Inquiry behavior

The contact form prepares a `mailto:` link and a copyable draft. The visitor reviews and sends it using their own email app. No message is submitted or claimed to have been sent by the website; form values are not stored. The displayed recipient remains `cindy@ateamdata.com`.

The old PHP endpoints and template assets are retained for repository compatibility but are not used by the redesigned pages. GitHub Pages does not execute PHP. The new primary pages no longer load jQuery, Bootstrap, the slider plugins, copied Lambda scripts, analytics or remote fonts.

## GPU reference matrix

The matrix covers representative server/data-center products from Volta to Rubin. Its eight rows include parallel architecture families and the Blackwell Ultra refresh; they are not eight successive chip generations. Columns distinguish PCIe cards, SXM modules / HGX platforms, CPU + GPU Superchips, selected DGX servers and NVL72 racks. Blank cells mean no example is included, not proof that no product exists. The page is not a live inventory or availability feed.

Search matches model names, short descriptions, families and formats. Family and format filters combine with search; the URL records the selection. CSV export includes only matching entries plus notes, NVIDIA references and the review date. Native expandable entries, source links and the complete table remain available without JavaScript. All filtering and exporting happen in the browser with no server or API calls. The matrix excludes consumer GeForce cards, desktop workstations and embedded products.

## Content and sources

Ateamdata's positioning is **sourcing and systems integration**, not server manufacturing. Do not add unsupported reseller authorization, stock, pricing, performance, customer, warranty or service-level claims. Catalog configurations are options to discuss; availability and commercial terms must be confirmed in the quotation.

The existing `benchmarks.html` address now contains a sourced GPU selection guide. It does not present third-party test results as Ateamdata benchmarks. Manufacturer references are linked on the catalog and guide pages. Specifications were checked on October 29, 2026; check the manufacturer before changing them.

Product images are stored locally; original source URLs are retained as `imageSource` in `site/products.mjs`. Supermicro and Dell images were sourced from Broadberry and Logixer product imagery respectively; the HPE image is from HPE's asset library. The data-center photograph is an existing repository asset (`images/slide-show5.webp`).
